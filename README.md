# FOMC Thesis

Project workspace for FOMC press-conference market and audio analysis.

## Structure

- `data/raw/`: source market data, metadata, audio, and transcripts.
- `data/processed/`: cleaned market and metadata tables, audio derivatives, diarization, extracted features, and the analysis dataset.
- `notebooks/`: project setup and analysis workflow.
- `models/`: model assets for WavLM and pyannote.
- `results/`: tables, figures, and reports.
- `scripts/`: reusable data preparation and feature extraction scripts.

Processed CSVs are currently empty placeholders. Add the corresponding source audio and transcript files under `data/raw/audio/` and `data/raw/transcripts/` before running audio workflows.
